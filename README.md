## Що зроблено

1. **Таблиця (варіант 2)** — ПІБ у першому рядку, група / ЛР / варіант у другому.
   Фон 1-го рядка `#028f8f`, 2-го — `#f5f502` (nn = 02); при наведенні кольори фону й тексту міняються місцями (`:hover`).
   CSS таблиці — у тезі `<style>` в `index.html`.
2. **Прапор Швейцарії (варіант 2)** — двічі, лише засобами CSS у `style.css`:
   за допомогою `position` (відступи `top`/`left`) і за допомогою `transform` (`translate` + `rotate`).
